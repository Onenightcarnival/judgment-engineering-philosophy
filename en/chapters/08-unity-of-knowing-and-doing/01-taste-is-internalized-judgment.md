# Taste Is Internalized Judgment

Judgment, once internalized, is called taste.

## Side by side

| | Judgment | Taste |
|---|---|---|
| Discernment | Takes a moment of thought | At a glance |
| Discipline | Takes a moment of restraint | No restraint needed |
| Reasons | Reasons first, then the conclusion | Conclusion first; reasons available when asked |
| Speed | Slow | Fast |

## Internalizing

When the same kind of judgment is repeated enough times, it no longer passes through thought.

There is no shortcut. Repetitions are the only input.

## Taste cannot be obtained directly

Skipping judgment to go after taste yields preference.

| | Preference | Taste |
|---|---|---|
| How it is put | "I like it" | "This is worth it" |
| Asked for reasons | Cannot give them | Can give them |
| Verified by time | No | Yes |

## For agents

An agent's taste is the judgment settled into rules, examples and principles.

| | A person | An agent |
|---|---|---|
| The mark of internalization | No need to think | No need to be told again each time |
| Where it is internalized | In the person | In structure |
