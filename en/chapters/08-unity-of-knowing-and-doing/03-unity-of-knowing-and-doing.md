# Unity of Knowing and Doing

Between knowing and doing there is a distance. The forming of judgment is the shrinking of that distance to zero.

## Five stages

| Stage | Knowing | Doing |
|---|---|---|
| Deference | Does not understand | Does as the baseline says |
| Discipline | Understands the principle | Gets it done by holding back |
| Discernment | Understands the mechanism | Knows what to do |
| Derivation | Understands the consequences | Knows how far to deviate |
| Unity | Knows | And so does |

## The mark of unity

There is no list of things "known but not yet done".

## For agents

For an agent, this distance is the distance between instruction and output.

| What shortens it | How |
|---|---|
| Rules | Make "violating" equal "not passing" |
| Examples | Make "doing as shown" cheaper than "starting from scratch" |
| Principles | Give the direction |

## The last line

The principle is simple. Has it been done.
