# The Agent Is a Student Who Can Be Taught

## Side by side

| | An adult | An agent |
|---|---|---|
| Takes guidance | Rarely | Yes |
| Changes through | Events | Instructions, examples, error messages |
| Where the change stays | In the person | In documents, rules and examples |
| In a new environment | Carried along | Left behind |
| Initiative | A few have it | Someone has to start it |

## It can be taught

Under step-by-step guidance, an agent's output can be polished until it is right.

The same guidance given to an adult mostly has no effect.

## What it was taught does not stay in it

Remove the instruction and it falls back to the default.

Every correction has to land somewhere:

| What the correction is | Where it lands |
|---|---|
| Something that can be stated | A rule |
| Something that cannot be stated but can be made | An example |
| Direction | Principles and design documents |

A correction that does not land is repeated next time.

## The teacher has to be good enough

The ceiling of what an agent can learn is the person teaching it.

## No distinction between people and agents

The order in which judgment forms is the same for both: deference, discipline, discernment, derivation.

What differs is the carrier.

- A person's judgment grows in the person.
- An agent's judgment lives in structure.
