# Copy the Best

Without understanding, copying the best in the field is rarely wrong.

## What the best contains

Every design choice in the best product has been filtered by the most users over the longest time.

Copying it borrows that filtering.

## Use it first, then copy

| | Has used the best in depth | Has not used it |
|---|---|---|
| Can tell which one is the best | Yes | No |
| Can see what makes it good | Yes | No |
| What gets copied | The design | The appearance |

## What a discussion produces

| Who is in the room | What the discussion produces |
|---|---|
| Someone has used the best in depth | That person speaks; the rest listen |
| Nobody has used it | Nothing better than copying |

When nobody in the room has used the best, cancel the discussion and go use it.

## For agents

Giving an agent one example from the best beats giving it ten descriptions.
