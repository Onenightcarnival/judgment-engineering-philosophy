# The Agent's Ceiling Is Its User's Discernment

An agent's output has to pass acceptance. The acceptance standard is the user's discernment.

## Three kinds of user

| User | Acceptance standard | What gets accepted |
|---|---|---|
| Cannot tell good from bad | The happy path runs | Anything that runs |
| Can tell, cannot say why | "Feels wrong, redo it" | Whatever happens to come out right after retries |
| Can tell and can say | An explicit end state | What matches the end state |

In the hands of the first kind, whatever the agent delivers is accepted.

## The same machine

The same model, the same tools, a different user: the output differs.

The difference comes from the user.

## Beyond the template

| Part of the task | Whom the output follows |
|---|---|
| Covered by the template | The template |
| Not covered by the template | The user's discernment |

Where the template runs out, the user's discernment shows for what it is.

## Conclusion

The agent has not replaced discernment.

It has lowered the cost of execution. Whether discernment is present now shows up in the output sooner.
