# A Personal Statement of Position

## Position

- The book states only the author's own views.
- It does not follow the crowd and does not lean on authority.
- It does not answer objections.
- It is not selling anything.
- It is written for those meant to read it.

## Preferences

| Preferred | Over |
|---|---|
| Declarative | Imperative |
| Explicit | Implicit |
| Functions | Classes |
| Composition | Inheritance |
| The simple solution | The one that looks advanced |
| What time has verified | What is popular now |
| Derivation | What others do |

## Style

1. Declarative.
2. No self-explanation; present only the design result.
3. Let structure make the logic visible at a glance.

## Limits

The judgments in this book, by the book's own standard, can only be verified by time.
