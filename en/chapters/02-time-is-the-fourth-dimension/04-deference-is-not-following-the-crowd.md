# Deference Is Not Following the Crowd

The two share the same action: doing what others do.

## Side by side

| | Deference | Following the crowd |
|---|---|---|
| What is followed | A result that time has verified | What most people are doing now |
| The basis | How many cycles it has survived | How many people are doing it now |
| When many do it | No points added | Points added |
| When nobody does it | No points lost | Points lost |

## The test

Remove the reason "many people use it now" and see what is left.

| What is left | It is |
|---|---|
| "It has survived many cycles" | Deference |
| Nothing | Following the crowd |

## Examples

| Practice | With "many people use it" removed |
|---|---|
| Storing business data in a relational database | Decades, verified by countless systems |
| Using this quarter's hottest orchestration framework | Nothing |
| Holding the index | Beats most active choices over the long run |
| Chasing this month's biggest gainer | Nothing |

## The same thing changes cells

When something has just become popular, following it is following the crowd.

After it has survived enough cycles, following it is deference.

The difference is time.
