# Everything Outside the Horizon Is Noise

Once the horizon is set, questions fall into two kinds: those inside it and those outside it.

The second kind is noise.

## What it looks like

| Horizon | Noise |
|---|---|
| A core library, measured in years | Which new framework topped the charts this week |
| A model selection, measured in quarters | A single change of rank on some leaderboard |
| A long-term holding, measured in decades | Which way this one interest-rate decision goes |

## The test

Once the answer is known, does the decision change.

| Answer | The question is |
|---|---|
| It changes | Signal |
| It does not change | Noise |

## Most questions are not worth answering

Answering a question takes time.

For noise, the correct investment is zero: no thinking, no looking up, no discussing.

A system has no obligation to explain each of its fluctuations.

## For agents

An agent handles everything in its context with care.

| What goes into the context | The agent's response |
|---|---|
| Signal | It handles it |
| Noise | It handles it just as carefully |

Filtering out noise is finished before the instruction is sent.
