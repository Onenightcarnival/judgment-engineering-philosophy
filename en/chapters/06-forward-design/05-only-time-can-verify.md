# Only Time Can Verify

A judgment is guaranteed in advance by derivation and verified afterwards by time. Between the two there is no instant evaluation.

## Four means

| Means | When it delivers | What it can confirm |
|---|---|---|
| Derivation | In advance | If the premises hold, the conclusion holds |
| Structure | On the spot | Coupling is in the wrong place |
| Tests | On the spot | Behavior matches expectations |
| Time | After the cycle has run its course | Whether the direction is right, whether it was worth it |

The first three all confirm "was it done correctly". Only the fourth confirms "was it worth it".

## A single outcome is not verification

| | Good outcome | Bad outcome |
|---|---|---|
| Right judgment | Deserved | Bad luck |
| Wrong judgment | Good luck | Deserved |

Looking at one outcome, the two cells in the same column cannot be told apart.

Top right and bottom left are both luck. Bottom left is the more dangerous: a wrong judgment was rewarded.

## Two things time supplies

- Repetitions. When the same judgment is repeated enough times, luck cancels out.
- A cycle. After one full cycle, what was right in the short run and wrong in the long run shows itself.

## While waiting

Write down the derivation at the time: premises, options, consequences. Compare when the time comes.

| When the time comes | Conclusion |
|---|---|
| Good outcome, premises held | The judgment was right |
| Good outcome, premises did not hold | Luck |
| Bad outcome, premises held | Go back through the derivation and find the missed consequence |
| Bad outcome, premises did not hold | The judgment was wrong |

Without a record, only the outcome is left when the time comes, and the table in the previous section is all there is.

## The judgment of people and agents

Whether a person's or an agent's judgment has improved is also left to time.

In the short run there is only one visible signal: they start pointing out what is missing from a design.
