# Discipline: Not Wavering on What Is Worth It

Discipline is not wavering on what is worth it.

## What makes one waver

| Disturbance | In a person | In an agent |
|---|---|---|
| Short-term swings | Changing course midway | Replacing the whole approach after one failure |
| Saving effort | Skipping the check | Adding an exemption so the check passes |
| Other people's opinions | Going along with the crowd | Following the user's mistaken premise |
| Time passing | Slackening | Forgetting constraints as the context grows |

## What discipline guards

Discipline guards what has already been judged worth it.

Persisting in something not worth it does not count as discipline.

## At the start

At the start there is no discernment yet. "Worth it" is supplied by the baseline, and discipline guards the baseline.

The order is discipline first, then discernment on top.

See [Chapter 3](../03-become-the-baseline-first/00-overview.md).

## Discipline cannot be taught

Explaining principles does not produce discipline.

A person's discipline is taught by events. An agent's discipline is written into structure.

See [Chapter 4](../04-write-discipline-into-structure/00-overview.md).
