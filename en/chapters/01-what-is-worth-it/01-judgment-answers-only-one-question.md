# Judgment Answers Only One Question

What is worth it.

## The same question

| Setting | The surface question | The actual question |
|---|---|---|
| Choosing a technology | Which framework to use | Which one is worth years of maintenance |
| Code review | Is this written correctly | Is this piece worth keeping |
| Discussing a requirement | How to build this feature | Is this feature worth building |
| Instructing an agent | How to make it do this right | What result is worth accepting |
| A meeting | What to think about this question | Is this question worth discussing |

## Two kinds of questions

| | How to do it | What is worth it |
|---|---|---|
| The answer comes from | Knowledge and execution | Judgment |
| Can an agent answer it for you | Yes | No |
| The cost of a wrong answer | Rework | The right method spent on something not worth doing |

Once the cost of execution dropped, the first kind went to agents.

Nobody answers the second kind for you.

## The two parameters of "worth it"

- For what goal.
- Over what horizon.

Without a horizon, "worth it" cannot be decided. See [Chapter 2](../02-time-is-the-fourth-dimension/00-overview.md).
