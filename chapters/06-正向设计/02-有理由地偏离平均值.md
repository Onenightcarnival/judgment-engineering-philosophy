# 有理由地偏离平均值

默认的产出是平均值。人照抄见过的东西，模型输出训练数据的均值，团队沿用主流做法。

偏离平均值需要理由。理由来自推导。

## 四种情况

| | 说得出理由 | 说不出理由 |
|---|---|---|
| 不偏离 | 遵从 | 从众 |
| 偏离 | 正向设计 | 标新立异 |

- 遵从与从众，动作相同。
- 正向设计与标新立异，动作相同。

落在哪一格，只看理由。

## 理由要写下来

一套 lint 规则是一条基准。每一处偏离，连同理由一起登记。

| 基准规则 | 偏离 | 写下的理由 |
|---|---|---|
| async 函数不带 timeout 参数 | 忽略 | timeout 参数是这里 API 的一部分 |
| async 函数里不做同步的路径操作 | 忽略 | 这类调用在本地，足够快 |
| 不使用 print | 命令行入口豁免 | 命令行的输出就是 print |
| 不使用易混淆的全角字符 | 忽略 | 文本是中文 |

两条约束让登记有效：

- 豁免必须指明豁免的是哪一条。
- 写不出理由的偏离，退回基准。

## 对 agent

模型的默认产出是平均值。指令里没有理由，它不偏离。

要它偏离，有两种给法：

- 给出理由。
- 给出偏离之后的样子。
