# 道理很简单，做到很难

知道和做到是两件事。

## 道理都很简单

- 小步提交。
- 想清楚再动手。
- 不为假想的需求写代码。
- 不值得做的需求，拒绝。
- 选定的方向，不为一周的波动改掉。

没有一条需要解释。

## 差距在哪里

道理知道一次就够。代价每一次都要付。

| 道理 | 每一次的代价 |
|---|---|
| 小步提交 | 多停下来几次 |
| 想清楚再动手 | 忍住马上开始的冲动 |
| 不为假想的需求写代码 | 忍住"顺手加上" |
| 拒绝不值得的需求 | 当场让人不高兴 |
| 不为波动改方向 | 看着别的方向短期更好，不动 |

## 再讲一遍没有用

再讲一遍道理，增加的是"知道"。"知道"本来就不缺。

## 对 agent

agent 知道所有的道理。

| 写进提示词的 | 上下文变长之后 |
|---|---|
| "保持简洁" | 退回冗长 |
| "不要过度设计" | 退回层层抽象 |
| "不要吞掉异常" | 退回 try 加日志 |

把道理在提示词里再写一遍，等于对人再讲一遍。

## 出路

出路有两条：

- 事。
- 结构。
