# 人教人教不会，事教人一次就会

## 两种教法

| | 人教 | 事教 |
|---|---|---|
| 形式 | 讲道理、提醒、评审意见 | 后果直接落在本人身上 |
| 改变的 | 知道 | 行为 |
| 要重复吗 | 要，而且无效 | 一次 |

## 事的三个条件

- 后果是真的。
- 后果落在本人身上。
- 后果来得够快，本人认得出它是哪个决定带来的。

缺一条，事退化成道理。旁观别人的事故，得到的仍然只是"知道"。

## 对人

改变行为的那件事，必须亲历。没有东西替代它。

亲历了也不保证改变。经历了事而不变的人是多数。

## 对 agent

agent 没有痛。它的事是当场失败的检查。

| 事 | 落在谁身上 | 多快 |
|---|---|---|
| lint 报错 | 写出这段代码的那一轮 | 当场 |
| 测试不过 | 同上 | 当场 |
| 构建失败 | 同上 | 当场 |

这些事可以提前造好。

## 对人，事也可以造一部分

把后果的到来提前。

| 后果出现在 | 认得出是哪个决定吗 |
|---|---|
| 提交时 | 认得出 |
| 评审时 | 大多认得出 |
| 上线后一个月 | 多半认不出 |

检查越靠前，事越像事。
