# 抄思想，不抄形状

## 两样东西

| | 思想 | 形状 |
|---|---|---|
| 是什么 | 它解决什么问题，凭什么解决 | 它在原来的语言和环境里长成的样子 |
| 搬到新环境 | 成立 | 变成负担 |

## 一个例子

把 Java 世界的标准工程框架搬到 Python。

| | 抄 | 不抄 |
|---|---|---|
| 思想 | 一个生态要有一套标准的工程框架 | |
| 思想 | 依赖由外部提供 | |
| 形状 | | 四层目录 |
| 形状 | | 接口与实现类成对出现 |
| 形状 | | 容器、工厂、继承体系 |

```python
# 抄了形状
class OrderService(ABC):
    @abstractmethod
    async def create(self, payload: OrderIn) -> Order: ...


class OrderServiceImpl(OrderService):
    def __init__(self, session_factory: SessionFactory) -> None:
        self._session_factory = session_factory

    async def create(self, payload: OrderIn) -> Order: ...


container.register(OrderService, OrderServiceImpl)


# 抄了思想
@router.post("/orders")
async def create_order(payload: OrderIn, session: AsyncSession = Depends(get_session)) -> Order: ...
```

依赖同样由外部提供。第二种用的是宿主语言自己的方式：函数的参数。

## 划线的依据

宿主的习惯。

借来的思想，用宿主自己的方式表达，并且克制。

## 检验

换一种语言，它还成立吗。

| 答案 | 它是 |
|---|---|
| 成立 | 思想 |
| 不成立 | 形状 |
