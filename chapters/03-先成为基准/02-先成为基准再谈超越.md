# 先成为基准，再谈超越

超越基准的第一步，是先达到基准。

## 成为基准

| 领域 | 基准 | 成为基准 |
|---|---|---|
| 投资 | 市场指数 | 持有指数 |
| Python 工程 | 社区通行的规范和工具链 | 格式化、lint、类型检查全开，先全绿 |
| 产品设计 | 同类里做得最好的那一个 | 先做到和它一样 |
| agent | 强模型加默认配置 | 先测出默认配置的表现 |

## 跳过这一步

没有成为基准就谈超越，分不清自己的改动是加分还是减分。

没有对照，就没有差值。

## 之后

成为基准之后，每一处偏离都有了对照。

| | 没有基准 | 有基准 |
|---|---|---|
| 一处改动的效果 | 凭感觉 | 与基准的差值 |
| 改坏了 | 不知道 | 退回基准 |

## 多数时候，停在基准就够了

达到基准已经好过多数主动偏离的结果。

剩下的事情是守住它。
