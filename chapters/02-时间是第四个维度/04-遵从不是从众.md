# 遵从不是从众

两者的动作相同：跟着别人做。

## 对照

| | 遵从 | 从众 |
|---|---|---|
| 跟的对象 | 被时间验证过的结果 | 当下多数人的做法 |
| 依据 | 它活过了多少个周期 | 现在有多少人在做 |
| 人多的时候 | 不加分 | 加分 |
| 没人做的时候 | 不减分 | 减分 |

## 检验

把"现在很多人在用"这条理由拿掉，看还剩什么。

| 剩下的 | 它是 |
|---|---|
| "它活过了很多个周期" | 遵从 |
| 什么都不剩 | 从众 |

## 例

| 做法 | 拿掉"很多人在用"之后 |
|---|---|
| 用关系型数据库存业务数据 | 几十年，无数系统验证过 |
| 用这个季度最热的编排框架 | 什么都不剩 |
| 持有指数 | 长期跑赢多数主动选择 |
| 追这个月涨得最多的那一只 | 什么都不剩 |

## 同一个东西会换格

一样东西刚流行时，跟它是从众。

它活过足够多的周期之后，跟它是遵从。

区别在时间。
