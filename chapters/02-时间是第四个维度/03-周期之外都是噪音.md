# 周期之外都是噪音

周期定下之后，问题分成两类：周期之内的，周期之外的。

后一类是噪音。

## 样子

| 周期 | 噪音 |
|---|---|
| 一个核心库，按年计 | 这周哪个新框架上了热榜 |
| 一次模型选型，按季度计 | 某个榜单上的单次排名变动 |
| 长期持有，按十年计 | 这一次利率决议的走向 |

## 检验

答案出来之后，决定会不会变。

| 答案 | 这个问题是 |
|---|---|
| 会变 | 信号 |
| 不会变 | 噪音 |

## 大多数问题不值得回答

回答一个问题要花时间。

对噪音，正确的投入是零：不想，不查，不讨论。

系统没有义务解释自己的每一次波动。

## 对 agent

agent 会认真处理上下文里的每一样东西。

| 放进上下文的 | agent 的反应 |
|---|---|
| 信号 | 处理 |
| 噪音 | 同样认真地处理 |

筛掉噪音，在发出指令之前完成。
