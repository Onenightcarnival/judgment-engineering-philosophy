# 品味是内化了的判断力

判断力内化之后，叫品味。

## 对照

| | 判断力 | 品味 |
|---|---|---|
| 眼光 | 要想一下 | 一眼 |
| 纪律 | 要忍一下 | 不用忍 |
| 理由 | 先有理由，再有结论 | 先有结论，问起来说得出理由 |
| 速度 | 慢 | 快 |

## 内化

同一类判断重复足够多次，不再经过思考。

内化没有捷径。次数是唯一的输入。

## 品味不能直接获得

跳过判断力去追求品味，得到的是偏好。

| | 偏好 | 品味 |
|---|---|---|
| 说法 | "我喜欢" | "这个值得" |
| 问起理由 | 说不出 | 说得出 |
| 经过时间验证 | 没有 | 有 |

## 对 agent

agent 的品味，是沉淀在规则、样板和原则里的判断。

| | 人 | agent |
|---|---|---|
| 内化的标志 | 不用想 | 不用每次重新交代 |
| 内化在哪里 | 身上 | 结构里 |
