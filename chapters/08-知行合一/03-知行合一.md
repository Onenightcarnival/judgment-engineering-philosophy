# 知行合一

知与行之间有一段距离。判断力的形成，是把这段距离缩到零。

## 五个阶段

| 阶段 | 知 | 行 |
|---|---|---|
| 遵从 | 不懂 | 照基准做 |
| 纪律 | 懂道理 | 靠忍住来做到 |
| 眼光 | 懂机制 | 知道该做什么 |
| 推导 | 懂后果 | 知道偏离到哪里为止 |
| 合一 | 知道 | 即做到 |

## 合一的标志

没有一张"知道但还没做"的清单。

## 对 agent

对 agent，这段距离是指令与产出之间的距离。

| 缩短距离的 | 做法 |
|---|---|
| 规则 | 让"违反"等于"通不过" |
| 样板 | 让"照做"比"另起炉灶"更省事 |
| 原则 | 给出方向 |

## 最后一条

道理是很简单。做到了吗。
