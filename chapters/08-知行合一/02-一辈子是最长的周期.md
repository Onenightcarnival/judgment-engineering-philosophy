# 一辈子是最长的周期

## 周期越长，值得的事越少

| 周期 | 留下来的事 |
|---|---|
| 一天 | 几乎每件事都显得重要 |
| 一年 | 少数几件 |
| 一辈子 | 很少的几件 |

## 最长的周期，最简单的做法

1. 选定很少的几件值得的事。
2. 用简单的、被时间验证过的方法去做。
3. 重复。
4. 不被打断。

## 代价

- 无聊。做法简单，每天相同。
- 孤独。验证要等很久，其间没有反馈。

## 换代

| | 寿命 |
|---|---|
| 一段代码 | 几年 |
| 一个框架 | 十年上下 |
| 一代模型 | 更短 |
| 做判断的方式 | 一辈子 |

工具换代。判断力不换代。
