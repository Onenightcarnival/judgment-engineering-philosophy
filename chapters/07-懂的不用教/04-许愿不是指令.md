# 许愿不是指令

## 对照

| | 许愿 | 指令 |
|---|---|---|
| 内容 | 想要的感觉 | 可检验的终态 |
| 例一 | "请务必拿下胜利" | "本周内，三个核心接口的 P99 降到 200 毫秒以下" |
| 例二 | "代码要优雅" | "`__init__.py` 里只有 import" |
| 例三 | "架构要清晰" | "领域之间没有直接的 import" |
| 接收方能做的 | 猜 | 做，然后自查 |
| 验收 | 凭感觉 | 对照终态 |

## 许愿的来源

说不清，是没看清。

许愿的人不知道终态长什么样。表达的问题，是眼光的问题。

## 指令的结构

```text
<终态>。看一下有没有<手段>可以实现。
```

- 终态由发指令的人给出。
- 手段交给接收方。

## 密度

一条指令里，每一句都改变接收方的行为。

删掉一句，产出不变，这一句多余。

## 许愿式开发

对 agent 许愿，然后重试，直到正向用例跑通。

产出的质量，停在"能跑"。
