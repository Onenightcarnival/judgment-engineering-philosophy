# 只会照抄见过的东西

不知道什么是好的，就照抄自己唯一见过的东西。

## 人和 agent 相同

| | 照抄的对象 |
|---|---|
| 人 | 仓库里已有的代码，上一个项目的做法 |
| agent | 上下文里的代码，训练数据里的常见写法 |

## 两个推论

- 样板决定上限。接收方见过的最好的东西，是它产出的上限。
- 坏的和好的扩散得一样快。一段烂代码合入之后，成为下一次照抄的对象。

守门守的是样板库。

## 做法

提供样板：工程模板、SDK、设计文档的范例。

多数人和多数 agent 的提升来自照抄样板。这是传递的主要通道。

## 两种载体

| | 原则 | 样板 |
|---|---|---|
| 形式 | 几句话 | 一段可以照抄的成品 |
| 对接收方的要求 | 高 | 低 |
| 管得到的范围 | 广 | 样板覆盖到的地方 |

## 样板的边界

样板没覆盖到的地方，接收方退回它原来的水平。
