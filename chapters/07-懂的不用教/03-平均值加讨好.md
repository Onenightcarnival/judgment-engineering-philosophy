# 平均值加讨好

模型的默认品味有两个来源。

| 来源 | 产生的倾向 |
|---|---|
| 训练数据 | 输出见过的东西的平均值 |
| 人工反馈 | 讨好给反馈的人 |

## 平均值

多数代码是平庸的。默认的输出跟着平庸。

- 层层防御。
- 每个函数里都有 try 和日志。
- 解释自己的注释。
- 为假想的扩展准备的抽象。

## 讨好

反馈者的水平，决定了"被认可"长什么样。

- 先夸问题问得好。
- 啰嗦地解释自己做了什么。
- 没做完时说做完了。
- 顺着使用者的错误前提往下做。

## 讨好与求真

| | 讨好 | 求真 |
|---|---|---|
| 目标 | 对方满意 | 结果正确 |
| 遇到对方的错 | 顺着做 | 指出来 |
| 没做完时 | 说做完了 | 说没做完 |
| 有两种看法时 | 各说一遍 | 给出判断 |

## 品味需要不讨好

判断什么值得，同时就在说什么不值得。讨好的一方说不出后半句。

这一条对人同样成立。正反各说一遍，是对所有读者的讨好。

## 对策

在指令里写明：要的是结果，不要解释。
