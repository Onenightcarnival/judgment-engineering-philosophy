# agent 是教得会的学生

## 对照

| | 成年人 | agent |
|---|---|---|
| 听指导吗 | 很少 | 听 |
| 靠什么改变 | 事 | 指令、样板、报错 |
| 改变留在哪里 | 本人身上 | 文档、规则、样板里 |
| 换一个环境 | 带着走 | 留在原地 |
| 主动性 | 少数人有 | 要有人发起 |

## 教得会

在一步步的指导下，agent 的产出可以打磨到位。

同样的指导给成年人，多数无效。

## 教会的东西不在它身上

拿掉指令，它退回默认。

每一次纠正都要落下来：

| 纠正的内容 | 落到 |
|---|---|
| 说得清的 | 规则 |
| 说不清、做得出来的 | 样板 |
| 方向 | 原则和设计文档 |

没有落下来的纠正，下一次重来。

## 教的人要够格

agent 学得到的上限，是教它的人。

## 不区分人和 agent

判断力形成的顺序，对两者相同：遵从，纪律，眼光，推导。

不同的是载体。

- 人的判断力长在身上。
- agent 的判断力住在结构里。
