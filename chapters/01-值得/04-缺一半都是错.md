# 缺一半都是错

判断力，是眼光和纪律同时在场。

## 四格

| | 有纪律 | 没有纪律 |
|---|---|---|
| 有眼光 | 判断力 | 看得准，做不到 |
| 没有眼光 | 做得到，方向错 | 随波逐流 |

## 有眼光，没有纪律

- 知道该重构，一直没动。
- 知道这个需求不值得做，接了。
- 评审时看出了问题，放过了。

结果与没有眼光相同。

## 有纪律，没有眼光

- 流程严格。
- 规范齐全。
- 指标全绿。
- 做出来的东西不值得做。

努力越多，浪费越多。

## 对 agent

| | 样子 |
|---|---|
| 有眼光，没有纪律 | 开头写得好，上下文变长之后退回默认 |
| 有纪律，没有眼光 | 严格执行指令，交出平均值 |

## 顺序

先纪律，后眼光。

1. 遵从基准，照着做。
2. 理解基准凭什么成立。
3. 改进。

## 合一

两者同时在场，并且不再需要用力，叫品味。见[终章](../08-知行合一/00-概述.md)。
