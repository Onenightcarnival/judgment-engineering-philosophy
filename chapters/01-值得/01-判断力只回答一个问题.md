# 判断力只回答一个问题

什么值得。

## 同一个问题

| 场景 | 表面的问题 | 实际的问题 |
|---|---|---|
| 技术选型 | 用哪个框架 | 哪个值得押上之后几年的维护 |
| 代码评审 | 这样写对不对 | 这一段值不值得留下 |
| 需求讨论 | 这个功能怎么做 | 这个功能值不值得做 |
| 给 agent 的指令 | 怎么让它做对 | 什么样的结果值得收下 |
| 一场会议 | 这个问题怎么看 | 这个问题值不值得讨论 |

## 两类问题

| | 怎么做 | 什么值得 |
|---|---|---|
| 答案来自 | 知识和执行 | 判断 |
| agent 能代答吗 | 能 | 不能 |
| 答错的代价 | 返工 | 把对的方法用在不值得的事上 |

执行的成本降下来之后，第一类问题交给了 agent。

第二类没有人代答。

## "值得"的两个参数

- 对什么目标。
- 在多长的周期里。

缺了周期，"值得"无法判定。见[第二章](../02-时间是第四个维度/00-概述.md)。
