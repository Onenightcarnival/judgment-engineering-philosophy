# 个人立场声明

## 立场

- 只表达作者自己的观点。
- 不追求从众，不依赖权威背书。
- 不回应反对意见。
- 没有推销的目的。
- 写给有缘人。

## 偏好

| 偏好 | 胜过 |
|---|---|
| 声明式 | 命令式 |
| 显式 | 隐式 |
| 函数 | 类 |
| 组合 | 继承 |
| 简单的方案 | 看起来高级的方案 |
| 被时间验证过的 | 当下流行的 |
| 推导 | 别人怎么做 |

## 写法

1. 声明式。
2. 不自我解释，仅呈现设计结果。
3. 通过结构让读者一眼看明白逻辑。

## 局限

书里的判断，按书里的标准，同样只能交给时间验证。
