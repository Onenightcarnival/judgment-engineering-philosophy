# 攻略加实操

眼光的形成有两步，顺序固定：先读攻略，再长期实操。

## 两步

| | 攻略 | 实操 |
|---|---|---|
| 是什么 | 前人整理好的机制和占优做法 | 亲手做，持续多年 |
| 给出的 | 好坏的标准 | 标准变成直觉 |
| 耗时 | 几周 | 几年 |
| 只有这一步时 | 说得出好坏，做不出来 | 重复自己已有的习惯 |

## 攻略在前

读完好的攻略，立刻分得出好坏。这一步不需要几年。

没读攻略就实操，练熟的是错误。

攻略要挑。一个领域里被时间筛选过的攻略只有几本。

## 实操的形式

最有效的实操是守门：长期评审和重构别人交上来的东西。

每一次评审都在回答同一个问题：这一段值不值得留下。回答的次数堆出眼光。

## 这条路没有痛

眼光教得会。条件是这个人自己去读，自己去练。

同样读了攻略的人，有的半年内变了样，有的没有变化。差别在主动性，攻略给不了。

## 对 agent

| | 人 | agent |
|---|---|---|
| 攻略 | 书 | 写给它的原则和设计文档 |
| 实操 | 多年的守门 | 样板，加上一次次纠正 |
| 实操的结果留在 | 本人身上 | 文档、规则、样板里 |

agent 的实操不留在它身上。每一次纠正要落到文档、规则或样板里，否则下一次从头开始。
