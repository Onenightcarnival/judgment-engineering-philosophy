# 没用过，就没有判断

人想象不出超过自己认知的东西。

判断一样东西的资格，来自用过它。

## 使用的深度

| 使用的深度 | 能判断的 |
|---|---|
| 没用过 | 无 |
| 试过一次 | 好不好上手 |
| 日常用了半年 | 哪里顺，哪里别扭 |
| 用它交付过，被它坑过 | 边界在哪里，哪些值得抄 |

读测评、听汇报、看演示，都停在第一行。

## 断层

没用过的人讨论一样东西，用的是想象。想象的上限是见过的东西。

一场讨论的结论，高不过在场用得最深的那个人。

在场没有人深度用过时，讨论没有产出。

## 补上断层

办法只有一个：去用。

## 对 agent

agent 的"用过"有两种：训练时见过，和在环境里实际跑过。

| 让 agent 下判断之前 | 得到的 |
|---|---|
| 什么都不给 | 训练数据里的平均印象 |
| 让它读源码和文档 | 基于这一版实际内容的判断 |
| 让它跑一遍 | 基于实际行为的判断 |

验收 agent 的产出同理。没深度用过这样东西的人，验收不了 agent 用它写出来的东西。
