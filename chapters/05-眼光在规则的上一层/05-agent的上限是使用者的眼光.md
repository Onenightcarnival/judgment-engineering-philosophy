# agent 的上限是使用者的眼光

agent 的产出要过验收。验收的标准是使用者的眼光。

## 三种使用者

| 使用者 | 验收标准 | 被收下的 |
|---|---|---|
| 看不出好坏 | 正向用例跑通 | 能跑的任何东西 |
| 看得出好坏，说不清 | "感觉不对，重来" | 反复重试后碰巧对的 |
| 看得出，说得清 | 明确的终态 | 符合终态的 |

第一种使用者手里，agent 交出什么都会被收下。

## 同一台机器

同一个模型，同一套工具，换一个人用，产出不同。

差距来自使用者。

## 模板之外

| 任务 | 产出跟着谁走 |
|---|---|
| 模板覆盖到的部分 | 模板 |
| 模板没覆盖的部分 | 使用者的眼光 |

模板用尽的地方，使用者的眼光现出原形。

## 结论

agent 没有替代眼光。

它把执行的成本降了下来。眼光的有无，由此更快地出现在产出里。
