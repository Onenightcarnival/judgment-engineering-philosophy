# 判断力的工程哲学

> 三部曲的第三部。前两部：[《大模型应用的工程哲学》](https://onenightcarnival.github.io/llm-engineering-philosophy/)、[《Agent 工程哲学》](https://onenightcarnival.github.io/agent-engineering-philosophy/)。

判断力只回答一个问题：什么值得。

- 眼光，是知道什么值得。
- 纪律，是在值得的事上不动摇。
- 判断力，是两者同时在场。

这本书讲判断力是怎么形成的。主角不区分人和 agent。

### 序章：为什么写第三本书

- 概述
- 不是又一本谈品味的书
- 个人立场声明

### 第一章：值得

判断力只回答一个问题：什么值得。眼光是知道什么值得，纪律是在值得的事上不动摇，两者同时在场才算判断力。

- 概述
- 判断力只回答一个问题
- 眼光：知道什么值得
- 纪律：在值得的事上不动摇
- 缺一半都是错

### 第二章：时间是第四个维度

对错取决于周期。先定周期，周期之外的问题都是噪音，长周期压过短周期。

- 概述
- 先定周期，再谈对错
- 周期之外都是噪音
- 大多数问题不值得回答
- 遵从不是从众

### 第三章：先成为基准

还没有判断力的时候，最好的判断是遵从被时间验证过的东西。超越基准的第一步是先成为基准。

- 概述
- 基准率不讲道理
- 先成为基准，再谈超越
- 照抄第一名
- 默认选被验证过的方案

### 第四章：纪律写进结构

知道和做到之间隔着的不是道理。人靠事教，agent 靠结构。规则装得下的部分，都该交给规则。

- 概述
- 道理很简单，做到很难
- 人教人教不会，事教人一次就会
- 规则装得下的，交给规则
- 好结果不等于好判断

### 第五章：眼光在规则的上一层

眼光判断的是这件事该不该在这里、用这种方式做。它来自深度使用和拆机制，靠攻略加实操练成。

- 概述
- 没用过，就没有判断
- 拆机制
- 攻略加实操
- 工具、范式、层级、松紧

### 第六章：正向设计

遵从够久才有资格偏离，偏离的依据是推导。眼光很快，但看不见行为上的错，验证是另一件事。

- 概述
- 推导先于观察
- 有理由地偏离平均值
- 眼光看不见的错
- 怎么知道判断力变好了

### 第七章：懂的不用教

判断力能不能传递，取决于接收方离它有多近。模型的默认品味是平均值加讨好。

- 概述
- 懂的不用教，要教的不会懂
- 平均值加讨好
- 三句话就够了
- 只呈现结果
- agent 是教得会的学生

### 终章：知行合一

- 概述
- 一辈子是最长的周期
- 知行合一
- 写给有缘人
